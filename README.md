# crazyflie-demos

A collection of demos for the Crazyflie ecosystem.

## Demos

| Type | Location | Description |
|------|----------|-------------|
| Scripts | `demos/scripts/cflib` | Python scripts using [cflib](https://github.com/bitcraze/crazyflie-lib-python) |
| Scripts | `demos/scripts/cflib2` | Python scripts using [cflib2](https://github.com/bitcraze/crazyflie-lib-python-v2), the async Rust-powered Python library |
| Scripts | `demos/scripts/rust` | Rust scripts using [crazyflie-lib-rs](https://github.com/bitcraze/crazyflie-lib-rs) |
| Firmware | `demos/firmware/` | Custom firmware demos |
| Hybrid | `demos/hybrid/` | Custom firmware combined with host-side scripts |

Each demo is self-contained with its own dependencies and instructions in its `README.md`.

## Getting Started

Browse the demos in `demos/` and follow the instructions in each demo's `README.md`.
